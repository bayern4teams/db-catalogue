`tests/test_live_collectors.py`. Derived from plan section 9 Phase 6 (P6-3, P6-6) and

were not read (they do not exist). State now: 11 controls pass, 26 behaviour tests are
`xfail(strict=True)` ("P6-3 not built" / "P6-6 not built"). `--runxfail` gives 26 failures, each
for the missing behaviour (no tokens: `None`/`AttributeError`/empty `sample_reads`; old probe
shape and `KeyError: 'max_threads'`; `sample_count` 40 and 14 instead of 13; budget unchanged;
`_tokenize_clickhouse` absent). None is a fixture error. `ruff check` clean on both files.

Fake client: `FakeClickHouse` answers the three catalog queries and then **evaluates** the value
reads it is sent (quoted column list, `db.table`, `LIMIT` literal or bound `{n:UInt64}` /
`%(n)s`; no `LIMIT` reads the whole table). The old probe (no `LIMIT`) therefore counts every
row, and an unparseable query raises, so a test cannot pass on a query the fake misread.
Non-default values everywhere (`sample_rows` 7, `read_timeout_seconds` 9, probe cap 13, token
cap 3) so a typed-in constant cannot match.

Self-check of the tests: a throwaway prototype of both items (scratchpad copy, not in the repo)
passes all 37 under `--runxfail`; six mutations of it (hard-coded `LIMIT`, uncharged read, nested
column read, `complete` always false, old probe settings, `SELECT *`) each fail 1-4 tests.
